# NAFLD 延伸檢測套組 — 全基因組定序（WGS）

核心 4 基因座套組（見 `NAFLD/`）之外的非酒精性脂肪肝（NAFLD）易感性變異延伸分析。

## 輸入資料

- **檔案**：`your_file.vcf.gz`（173 MB，壓縮 VCF 格式）
- **變異偵測工具**：DeepVariant v1.5.0
- **參考基因組**：GRCh37（hg19）
- **樣本編號**：ULMEDCBB3A73_ULMEDCBB3A73

## 分析方法

1. 透過 **Ensembl VEP REST API**（GRCh37 端點）解析每個 rsID 的 GRCh37 座標。
2. 使用 `awk` 單次掃描 VCF，檢查各基因座及完整基因區域（PNPLA2、CIDEB、MERTK）。
3. 透過 **Ensembl VEP** 註解基因區域變異，並交叉比對 **gnomAD** 確認等位基因頻率。

### APOE ε2/ε3/ε4 單倍型

APOE 單倍型由兩個 SNP 定義：**ε2**（rs429358-T、rs7412-T）、**ε3**（rs429358-T、rs7412-C）、**ε4**（rs429358-C、rs7412-C）。

- rs429358：**C/C**
- rs7412：**C/C**

**結果：APOE ε4/ε4（同型合子）。**

ε4 等位基因與阿茲海默症風險增加（同型合子相較 ε3/ε3 約 12 倍）、心血管疾病，以及與肝臟相關之肝脂肪含量增加及 NAFLD 風險相關。此為本套組中最重要的發現，建議與臨床醫師討論。
