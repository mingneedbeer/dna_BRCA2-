# BRCA2 基因變異分析 — 全基因組定序（WGS）

分析全基因組定序（WGS）資料，篩檢 **BRCA2** 基因中的致病性突變。

## 輸入資料

- **檔案**：`your_file.vcf.gz`（173 MB，壓縮 VCF 格式）
- **變異偵測工具**：DeepVariant v1.5.0
- **參考基因組**：GRCh37（hg19）
- **樣本編號**：ULMEDCBB3A73_ULMEDCBB3A73

## 分析方法

1. 從 VCF 中擷取 BRCA2 基因區域（`chr13:32,889,611–32,973,805`，GRCh37）所有通過品質篩選（PASS）的變異，共 **68 個變異**。
2. 將變異轉換為 HGVS 命名法，並透過 **Ensembl VEP REST API**（GRCh37 端點）查詢功能影響註解。
3. 針對錯義突變，交叉比對 **ClinVar**（NCBI）與 **gnomAD** 資料庫，確認臨床意義與等位基因頻率。

使用工具：`bcftools`（透過 Homebrew 安裝）、Python 3、Ensembl VEP REST API、NCBI E-utilities。

## 分析結果

**未偵測到致病性或可能致病性的 BRCA2 突變。**

### 功能影響摘要

| 影響等級   | 數量 | 說明                                           |
|------------|-----:|------------------------------------------------|
| 高（HIGH）         |    0 | 無截短突變、移碼突變或剪接破壞變異               |
| 中（MODERATE）     |    2 | 錯義突變（兩者皆為良性 — 見下表）                  |
| 低（LOW）          |    3 | 同義突變（無蛋白質序列改變）                      |

### 錯義突變

兩個錯義突變皆為一般族群中常見的**良性多態性**。

| 變異位置（GRCh37）   | dbSNP     | 基因型   | 蛋白質變化         | ClinVar         | gnomAD 頻率 | 備註                                  |
|----------------------|-----------|----------|--------------------|-----------------|-------------|---------------------------------------|
| chr13:32906729 A>C   | rs144848  | HET (0/1)| p.Asn372His (N372H)| **良性**（專家小組審核） | ~24%  | 常見多態性；功能實驗證實不具致病性         |
| chr13:32929387 T>C   | rs169547  | HOM (1/1)| p.Val2466Ala (V2466A)| **良性**     | ~98%      | 近乎固定之多態性；OncoKB 評估：「可能中性」 |

### 變異詳細說明

- **N372H（rs144848）**：全球約 24% 族群攜帶此變異。ClinVar 經 ENIGMA 專家小組審核，分類為良性。功能實驗將其歸類為 IARC 第一類（非致病性）。位於第 10 外顯子，在 DNA 結合域之外。

- **V2466A（rs169547）**：BRCA2 最常見的變異之一，等位基因頻率約 98%。ClinVar 分類為良性。位於 FANCD2 互動域。OncoKB 評估為「可能中性」。

## 重現分析

```bash
# 從 VCF 擷取 BRCA2 區域變異
gunzip -c your_file.vcf.gz | \
  awk -F'\t' '$1=="chr13" && $2>=32889611 && $2<=32973805 && $7=="PASS"'

# 透過 REST API 查詢 VEP（GRCh37）
# 端點：https://grch37.rest.ensembl.org/vep/human/hgvs/{HGVS_NOTATION}
```
